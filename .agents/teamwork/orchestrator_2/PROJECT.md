# Project: Ansh Rudra Portfolio Elevation Blueprint & Adversarial Audit

## Mission & Scope
Deliver a brutal adversarial critique and elevation blueprint for Ansh Rudra's portfolio website across 5 specialized pillars to elevate the website into an ultra-premium, high-craft benchmark.

## Architecture & Pillars
1. **Pillar 1: Luxury Visual & Surface Architect (Linear / Apple Tier)**
   - Target files: `src/app/globals.css`, `src/components/`, `tailwind.config.*`, layout styling, dark mode elevation surfaces, hairline borders (`rgba(255,255,255,0.08)`), specular highlights, typography pairing (`Fraunces`/`Instrument Serif` + `Commit Mono`/`Geist`), asymmetric layouts, anti-slop enforcement.
2. **Pillar 2: 3D Mascot & Character Animator (Aira Lifelike Realism)**
   - Target files: `src/components/3d/Aira3DModel.tsx`, `src/components/3d/AiraCompanion.tsx`, `src/data/airaDialogues.ts`, related 3D assets/shaders.
   - Rigging, bone tracking (`mixamorig:Head`, `mixamorig:Neck`), responsiveness, stride cadence, clip crossfading, natural human postures, dialogue matrix (zero emojis, 1000+ permutations, <12s immediate comeback triggers).
3. **Pillar 3: High-Ticket B2B Conversion Strategist ($10k–$25k Retainers)**
   - Target files: `src/components/sections/`, `src/components/calculator/`, ROI arbitrage calculator, intake flow, value proposition, loss-aversion messaging, positioning as elite Automation Engineer & Behavioral Strategist.
4. **Pillar 4: Audio Designer & Tactile Motion Choreographer (Multi-Sensory Craft)**
   - Target files: audio synthesis/playback modules, soundwave animations, micro-interactions (150ms-250ms), preloader curtain curve morph (Dennis Snellenberg curve morph), Lenis smooth scroll calibration.
5. **Pillar 5: Developer Tools & Interactive Systems Architect (Software Workbench Tier)**
   - Target files: `src/components/scraper/`, `src/components/terminal/`, command palette (`Cmd+K`), live DOM extraction telemetry, Playwright Python script generator, hotkeys, workbench feel.

## Requirements per Critic Deliverable
- Exact component, line number, or CSS rule references in `d:/Projects/Portfolio website`.
- Unsparing rationale explaining why the element falls short of an ultra-premium standard.
- Severity ranking (Blocker, Critical, Major, Minor, Polish).
- Specific, production-ready code modifications to resolve the flaw.

## Master Synthesis Deliverable
- 5 comprehensive distinct critique sections for each pillar.
- Master Elevation Blueprint.
- Prioritized Top-10 Roadmap of highest-impact visual, technical, and conversion improvements.
