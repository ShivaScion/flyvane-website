# Intentional UI/UX: Handcrafted & Non-AI Web Standards

## Core Tenets of Human-Crafted Web Design

### 1. Asymmetry & Broken Grids
- Avoid rigid, repetitive symmetry across every section.
- Mix full-bleed hero banners with offset editorial copy columns.
- Use staggered cards or list-detail hybrid layouts where hovering an item highlights an interactive visual preview.

### 2. High-Fidelity Micro-Interactions
- **Cursor & Magnetic Interactions:** Subtle magnetic pull on action buttons, or custom cursor highlights on interactive media.
- **Hover Micro-Delights:** Subtle scale transforms (`scale-[1.01]`), smooth border illumination (`border-white/20`), or background gradient shifting on card hover.
- **Interactive Previews:** Instant visual previews on project hover without requiring a full page navigation.

### 3. Tactile Dark Mode & Lighting
- **No Pure Black Voids:** Avoid `#000000` backgrounds with blinding `#ffffff` text. Use rich charcoal `#0c0d0e` or obsidian `#09090b` paired with soft off-white `#ededed`.
- **Subtle Ambient Radiance:** Use understated top-edge borders on cards (`box-shadow: inset 0 1px 0 0 rgba(255,255,255,0.1)`) to simulate light catching glass/metal bevels.
- **Surface Elevation:** Distinguish card levels with subtle tone shifts, not heavy blur shadows.

### 4. Content-Driven Rhythm
- Let project imagery, typography, and case study narrative take center stage.
- Treat every project entry like an editorial magazine spread rather than an e-commerce thumbnail.
