# Flyvane — Interactive 3D Digital Infrastructure & Strategic Operations

Official high-craft website for **Flyvane** — uniting autonomous engineering, workflow automation, and market strategy into a singular operational engine.

---

## Technical Stack & Architecture

- **Core Framework:** React 18 + Vite + TypeScript
- **3D Spatial Graphics:** Three.js (Procedural anime-inspired character rig, conduit pipelines, obsidian lighting)
- **Design System:** Tailwind CSS (Obsidian dark aesthetic, hairline translucent borders, intentional layout asymmetry)
- **Typography:** Syne (Display), Instrument Serif (Editorial Italics), Plus Jakarta Sans (Body), JetBrains Mono (Telemetry/Code)
- **Audio & Speech Engine:** Web Speech Synthesis calibrated with natural feminine pitch and pacing
- **Workbench & Tools:** Capability-aware interactive terminal with bounded live web inspection and Playwright generation

---

## Modes

1. **Machine Mode:** Autonomous workflow engineering, high-throughput data pipelines, zero-data-loss architecture, and CEH-certified security.
2. **Mind Mode:** Category diagnosis, positioning architecture, asymmetric narrative development, and editorial engine design.
3. **Hybrid Mode:** The unified engine where autonomous systems scale strategic market operations.

## Quick Start (Development & Production)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
# Server will start at http://localhost:3000
```

### 3. Build for Production
```bash
npm run build
# Outputs optimized static bundle to dist/
```

### 4. Preview Production Build
```bash
npm run preview
```

---

## Instant Hosting & Deployment

- **Vercel:** Configured out of the box (`vercel.json` included). Push to GitHub and deploy in one click.
- **Netlify:** Pre-configured with `netlify.toml`.
- **Cloudflare Pages / GitHub Pages:** Point build output to `dist/` with build command `npm run build`.
